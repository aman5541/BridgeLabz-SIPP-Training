Question -> 1.

Define an enum called TrafficLight:
    - RED
    - GREEN
    - YELLOW

Define a class SignalController:
    Property:
        - current (starts as RED)

    Method switchLight():
        If current is RED:
            Set current to GREEN
        Else if current is GREEN:
            Set current to YELLOW
        Else:
            Set current to RED

    Method showLight():
        Print "Current Light: " + current

Main:
    Create a new SignalController called signal
    Call signal.showLight()      // Shows RED
    Call signal.switchLight()    // Switches to GREEN
    Call signal.showLight()      // Shows GREEN
