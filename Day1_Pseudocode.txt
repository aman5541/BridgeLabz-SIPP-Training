Class Pet:
    Properties:
        - name
        - age
    Constructor(name, age):
        Set this.name = name
        Set this.age = age

Class Dog inherits from Pet:
    Property:
        - breed
    Constructor(name, age, breed):
        Call Pet constructor with name and age
        Set this.breed = breed

Class Cat inherits from Pet:
    Property:
        - isIndoor
    Constructor(name, age, isIndoor):
        Call Pet constructor with name and age
        Set this.isIndoor = isIndoor

Class Bird inherits from Pet:
    Property:
        - color
    Constructor(name, age, color):
        Call Pet constructor with name and age
        Set this.color = color

Main:
    Create Dog d = new Dog("Buddy", 3, "Labrador")
    Create Cat c = new Cat("Whiskers", 2, true)
    Create Bird b = new Bird("Tweety", 1, "Yellow")

Variables:
    currentText ← ""
    undoStack ← empty stack

Function type(text):
    Push currentText into undoStack
    currentText ← currentText + text

Function undo():
    If undoStack is not empty:
        currentText ← Pop from undoStack

Function showText():
    Print currentText

Example:
    type("Hello ")
    type("World")
    showText()     → prints "Hello World"
    undo()
    showText()     → prints "Hello "
